# Network Program Detector

Network Program Detector - это программное обеспечение, написанное на Python, которое позволяет определить, на каких устройствах в локальной сети установлена та или иная программа.

## Возможности

- Сканирование локальной сети для обнаружения подключенных устройств
- Определение на каких устройстах установленна программа
- Поддержка различных операционных систем (Windows, Linux)

## Требования

- Python 3.7 или выше
- Библиотеки:
  - `platform`
  - `socket`
  - `subprocess`
  - `winreg`
  - `scapy`

## Установка

1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/URAN2404/Seeker_PO.git
	```
2. Перейдите в директорию проекта:
   ```sh
   cd Seeker_PO
   ```
3. Установите необходимые библиотеки:
   ```sh
   pip install -r requirements.txt
   ```

## Использование

1. Запустите скрипт сканирования:
   ```sh
   python main.py
   ```
2. Следуйте инструкциям на экране.
